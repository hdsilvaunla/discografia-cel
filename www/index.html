🔄Google Drive

✅ 100% gratis — Sin Google Cloud, sin tarjeta, sin API Key.
Usá un Google Apps Script como puente a tu carpeta de Drive.
1Crear carpeta de backups en Drive
  1. En el celular o PC abrí drive.google.com
  2. Creá una carpeta, por ejemplo Discografia_Backups
  3. Ahí van a vivir los archivos .json exportados
2Copiar el ID de la carpeta
  1. Abrí la carpeta en Drive
  2. La URL se ve así: https://drive.google.com/drive/folders/1ABC…xyz
  3. Copiá solo 1ABC…xyz — ese es el FOLDER_ID
3Crear el proyecto en Apps Script
  1. Abrí https://script.google.com
  2. Tocá Nuevo proyecto
  3. Borrá el código de ejemplo
  4. Tocá Copiar código abajo y pegalo
  5. Reemplazá PEGÁ_AQUÍ_EL_ID_DE_LA_CARPETA por tu FOLDER_ID
/**
 * Discografía Viewer — Puente Google Drive (solo lectura)
 */
var FOLDER_ID = 'PEGÁ_AQUÍ_EL_ID_DE_LA_CARPETA';

function doGet(e) {
  e = e || { parameter: {} };
  var action = (e.parameter.action || 'list').toLowerCase();
  try {
    if (action === 'list') return json_(listFiles_());
    if (action === 'get' || action === 'download') {
      var id = e.parameter.id;
      if (!id) return json_({ error: 'Falta parámetro id' });
      return json_(getFile_(id));
    }
    return json_({ error: 'Acción desconocida: ' + action });
  } catch (err) {
    return json_({ error: String(err && err.message ? err.message : err) });
  }
}

function listFiles_() {
  var folder = DriveApp.getFolderById(FOLDER_ID);
  var it = folder.getFiles();
  var files = [];
  while (it.hasNext()) {
    var f = it.next();
    var name = f.getName();
    if (!/\.json$/i.test(name)) continue;
    files.push({
      id: f.getId(),
      name: name,
      modifiedTime: f.getLastUpdated().toISOString(),
      size: f.getSize()
    });
  }
  return { files: files };
}

function getFile_(id) {
  var file = DriveApp.getFileById(id);
  var text = file.getBlob().getDataAsString('UTF-8');
  return JSON.parse(text);
}

function json_(obj) {
  return ContentService
    .createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

⚖️Aviso legal y términos de uso

🔒
Solo consulta del catálogo
Versión — · —

Discografía Viewer es un visor personal de catálogo musical. NO descarga, NO aloja, NO transmite y NO distribuye música ni contenido protegido por derechos de autor. Toda la información mostrada proviene exclusivamente de la lista .json que el usuario carga manualmente en este dispositivo.

✅ Lo que SÍ hace:
  • Mostrar la metadata de tu colección personal de CDs
  • Leer y consultar la lista cargada (sin modificarla)
  • Abrir enlaces externos ya guardados en la lista
  • Buscar el álbum en plataformas oficiales
  • Exportar copias de seguridad JSON/CSV de tu propia lista
🚫 Lo que NO hace:
  • Descargar archivos de audio, video o imágenes protegidas
  • Almacenar archivos multimedia en el dispositivo
  • Saltar sistemas de pago, DRM o suscripciones
  • Compartir archivos entre usuarios
  • Abrir dominios no oficiales
  • Enviar tus datos a servidores externos
🔐 Privacidad y datos:
  • Todo se guarda en localStorage
  • Si configurás Drive, tus backups van a tu propia cuenta
  • No hay analytics, no hay telemetría
  • Podés vaciar todo desde Más → Vaciar colección local
⚠️ Responsabilidad del usuario:
  • Sos el único responsable del origen y contenido de la lista
  • Debés poseer los CDs originales o tener derecho legítimo
  • El uso indebido de enlaces externos es tu responsabilidad
  • El autor no se hace responsable por daños derivados
Al continuar se registra una firma digital local (SHA-256).
